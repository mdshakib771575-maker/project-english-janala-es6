# 📖 English Janala

An interactive English vocabulary learning web application built with **HTML**, **Tailwind CSS**, **DaisyUI**, and **Vanilla JavaScript (ES6)**. The application helps users learn English vocabulary through interactive lessons, detailed word information, pronunciation support, and a clean, responsive user interface.

## 📌 Features

- 📚 Browse vocabulary by lessons
- 🔍 Search words instantly
- 📖 View detailed word information
- 🔊 Listen to word pronunciation
- 📝 Display meanings, examples, and synonyms
- ⚡ Dynamic data fetched from REST API
- ⏳ Loading spinner for better user experience
- 📱 Fully responsive design
- 🎨 Pixel-perfect UI based on the Figma design

```bash

```

### Open the project

Simply open the `index.html` file in your browser.
